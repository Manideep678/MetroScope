🚇 MetroScope: Strategic Metro Expansion using Machine Learning
📌 Overview

MetroScope is a data-driven urban planning system that predicts optimal metro station locations using machine learning models like Random Forest and XGBoost.

The project analyzes real-world urban data such as population density, infrastructure, traffic, and development trends to recommend efficient metro expansion strategies.

🎯 Objective
Predict optimal metro station locations in Chennai
Learn patterns from cities like Bangalore and Hyderabad
Apply machine learning for smarter urban infrastructure planning

🚀 Key Features
Multi-source data integration (GeoIQ, MagicBricks, Google Maps API)
Machine learning models: Random Forest & XGBoost
Geospatial data processing
Map-based visualization of predicted metro routes
Model evaluation using Accuracy & F1-score

Random Forest	~81%	~87%

XGBoost performed best and was used for final predictions.
